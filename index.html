Master Plan to Build Full HR Team Support on The Matrix (15 Steps) — Click to Toggle One sentence per bullet, plain non-technical terms
  • 1Split the single HR human-only switch into two separate switches, one that keeps HR data out of the Oracle learning dataset (stays on) and one that blocks agents from running HR tickets (turns off).
  • 2Add the HR Support Desk team to the workflow settings with its own ticket status names so agents can move HR tickets to In Progress and In Review.
  • 3Fix the ticket moving step so it always uses the ticket's own team instead of silently defaulting to the legal team.
  • 4Let the triage step read task type labels on HR tickets instead of only recognizing legal team labels.
  • 5Apply one standard label per task type to all 218 HR tickets so routing is predictable (34 labels in total).
  • 6Send document tasks to the existing legal document engine, send email and scheduling tasks to the existing general engine, and send external lookups to new connectors built one at a time.
  • 7Require a named person's approval in Slack before any email, signature packet, account change, or external order leaves the system.
  • 8Keep sensitive data (Social Security numbers, bank details, ID documents, health information) out of prompts, tickets, and the Oracle dataset, and keep signed documents in the legal repo under access control.
  • 9Build the connectors in this order based on value and effort: BoldSign (already configured), Checkr, OIG and SAM, NPPES, license boards, Slack admin, Microsoft 365 admin, BILL, and ADP last because PEO access is restricted.
  • 10Teach Agent Smith to build a full parent new-hire ticket with the right sub-issues for each of the four entities and to respect dependencies such as IT access only after Checkr clears.
  • 11Give every sub-issue a due date computed from the start date so reminders and escalations run without a person watching.
  • 12Add missing templates to the legal repo (offer letter, engagement letter, contractor agreement, NDA and non-solicit, arbitration) with state specific variants reviewed by counsel.
  • 13Roll out in five phases: documents, then onboarding emails and tracking, then screening connectors, then credentialing and payroll, then training.
  • 14Use HRSUP-172 as the first end-to-end test, then run one complete parent ticket for a new hire before opening the door to all task types.
  • 15Record on every ticket what the agent produced, who approved it, and when, so the HR team can audit any step.
